三分钟上手

  1. 配模型：打开「设置」，填模型名称、API 地址、密钥，点「测试连接」。显示成功后点「保存」。
  2. 选标的：回「分析」页，勾选要看的股票。想加新的去「标的」页。
  3. 点开始：点「开始分析」，进度条下面会逐只显示进展，一只大约 3~15 秒。
  4. 读结论：结果卡片点开看细节。方向只是参考，真正要盯的是「触发条件」和「失效条件」。

没配密钥也能用：点「不调模型，只跑数据」，能拿到全部客观因子和一份保守的规则结论，不消耗任何额度。

连密钥都还没有，想先看看界面长什么样？

项目里带了一个假模型，专门用于这种情况：

  1. 在项目目录打开终端，执行 node tools/mock-llm.js，保持窗口开着。
  2. 回到界面「设置」，填：模型名称 mock-model，API 地址 http://127.0.0.1:8799/v1，密钥随便填几个字符。
  3. 点「测试连接」，应显示成功。然后就能正常点「开始分析」了。

假模型不会真的分析，它只是把流程跑通、让你看清结果长什么样。等你拿到真密钥，改一下设置就行。

结果怎么读

字段含义
方向买入 / 加仓 / 持有 / 减仓 / 观望，五选一。这是基于当前数据的一个倾向，不是指令。
确信度0~100。分低说明数据缺口大或因子互相打架，此时方向本身参考价值有限。
关键价位止损价、止盈价、支撑、压力。都是具体数字，来自近 20/60 日高低点与成交密集区。
触发条件满足什么情况才执行。条件没到就不动手。
失效条件出现什么情况这个结论就作废。这是最该盯的一栏。
依据链条因子 → 结论 → 建议的完整推导。每条都带数值、时间、来源，可以逐条核对。
数据完整度五个维度里有几个取到了数据。点开能看到具体缺什么。
「不适用」和「缺失」不是一回事

比如 ETF 没有财务报表、没有 PE/PB、没有北向持股，这是标的本身不具备，不是数据没取到。工具把这类标成「不适用」，不会算作数据质量差，也不会因此降低确信度。

只有真正该有却没取到的，才算「缺失」。

五个维度

维度看什么
基本面最新报告期的营收与净利同比、ROE、毛利率、PE/PB、所属行业。用来判断业绩是在变好还是变差。
资金面主力资金净流入、融资余额变化、北向持股、成交额与换手。用来判断有没有真金白银在动。
技术面均线排列、回归斜率、量价形态、支撑压力、成交密集区。趋势判定在拟合度低时会自动降级为「震荡」，避免把噪声当趋势。
情绪面用新闻标题做词频打分，加上大盘当日表现。这是启发式判断，不是事实结论，看到异常要自己核实原文。
宏观与政策人民币汇率、原油、黄金。政策取向本工具不接政策文本源，所以明确不做判断，避免编造。
「成交密集区」是什么，为什么比支撑压力有用

把最近 20 天的成交量按价格分档统计，成交量最集中的那一段，就是大部分人的持仓成本区。

价格跌回这个区间，容易被套的人会想解套卖出，形成抛压；反过来站稳了这个区间，说明成本盘换手完成。它比单纯的高低点更接近真实的筹码分布。

中美联动

用美股隔夜表现当先行指标，判断 A 股这只票今天是跟着外盘走，还是走自己的逻辑。判定规则：

判定条件怎么理解
联动方向相同，幅度差小于 3 个百分点外盘是主要驱动，隔夜情绪传导有效
联动（幅度背离）方向相同，但幅度差 3 个百分点以上外盘有影响，但本土资金或基本面在起作用
背离方向相反这只票短期由本土因素主导，不要照外盘方向外推

四条传导路径都会列出来：估值传导（中期慢变量）、情绪传导（次日开盘半小时最有效）、外资偏好（看汇率与成交额）、产业链映射（龙头对应 A 股订单预期，时滞以周计）。

出错时怎么办

模型调用失败

情况工具的处理
限流 429、服务端 5xx、网络中断自动等一会儿重试，次数在设置里配
密钥错 401/403不重试，直接提示检查密钥
模型名或地址错 400/404不重试，直接提示检查模型名与地址
配额不足不重试，提示充值

重试都失败后，会用已经采集到的客观数据生成一份规则结论，字段完整，并标明「这是降级结果，未经模型推理」。此时不要据此调仓。

模型输出格式不对

模型没按格式返回是常事。工具会逐级尝试修复：直接解析 → 从代码块里抠 → 从混杂文字里截取 → 修尾逗号与引号 → 逐字段正则提取。全都失败才转规则降级。任何一级都不会缺字段，批量任务不会因此断链。

数据取不到

该维度标为不可用，在结果里写清楚缺什么，对应维度记 0 分（中性），确信度会相应下降。不会用假数字充数。

目录与文件

你日常只会碰两个东西：双击 start.bat 启动，在界面里操作。其余文件不需要动。

路径是什么
start.bat双击启动（Windows）。关掉黑窗口即停止服务。
server.js本地服务，界面和接口都由它提供。
public/界面三个文件：页面、脚本、样式。
lib/取数、算因子、调模型、解析输出的核心代码。
data/config.json你的设置都在这里。删掉会恢复默认示例。
data/history/每次分析自动存档，就是「记录」页看到的内容。
tools/mock-llm.js没密钥时用的假模型，想先看效果就运行它。
cli.js命令行模式，给批量或定时任务用，日常不需要碰。
tests/自检脚本，想确认代码没坏可以跑一下。

所有数据都在 data/ 一个目录里。备份就复制它，换电脑也只搬它。

已知限制

  • 数据来自公开接口，不是交易所直连；盘后拿到的就是当天收盘快照，不是实时逐笔。
  • 北向持股是季度披露，有明显时滞，不能当当日流向看。
  • 情绪分是新闻标题词频的启发式打分，属于媒体二手信息，看到异常请自己核实原文。
  • 政策取向不做判断，因为没接政策文本源。宁可不说，也不编。
  • PE 历史分位部分接口不返回，此时会如实写「接口未提供」，不假装有分位。
  • 本工具不预测涨跌、不自动下单、不承诺收益。它只负责把客观数据整理清楚，把逻辑链条摆出来，决策和后果由你自己承担。
